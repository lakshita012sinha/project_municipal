# Image Setup Instructions

To complete the login template setup, please save the following images to their respective locations:

## Required Images:

1. **Rajasthan Government Logo** (`raj.png`)
   - Save to: `static/images/logo/raj.png`
   - This should be the official Rajasthan Government logo (the one with Ashoka Chakra)
   - Recommended size: 80px x 80px (will be auto-resized)

2. **Favicon** (`raj_favicon.png`)
   - Save to: `static/images/logo/raj_favicon.png`
   - This should be a smaller version of the logo for browser tab icon
   - Recommended size: 32px x 32px or 16px x 16px

3. **Rajasthan Map Outline** (`map_outline.png`)
   - Save to: `static/images/outline/map_outline.png`
   - This should be an outline/silhouette of Rajasthan state map
   - Recommended size: 200px x 200px (will be auto-resized)
   - Should be in white/light color to show on the gradient background

## How to Save:
1. Right-click on each image you provided
2. Save them with the exact filenames mentioned above
3. Place them in the correct directories as specified

## After saving the images:
- The login page will display the official Rajasthan Municipal design
- The favicon will appear in the browser tab
- The map outline will show on the left side of the login form
